Our Programs

Structured learning paths designed to take students from curious beginners to confident creators.

Curriculum 1

Foundation program for Grade 6 and below

1

Basic Computer Skills

Learn fundamental computer operations, file management, typing skills, and digital safety. Build confidence with technology and establish a strong foundation for all future learning.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion
2

Scratch Programming Fundamentals

Introduction to programming concepts using Scratch's visual block-based interface. Learn about loops, conditionals, variables, and basic programming logic through fun, interactive projects.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion
3

Introduction to Game Design

Create your first interactive games and animations. Learn about sprites, backgrounds, sound effects, and user interaction while developing creative problem-solving skills.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion

Curriculum 2

Advanced program for Grade 7 and above

1

Scratch Programming

Advanced Scratch programming with complex algorithms, data structures, and sophisticated project development. Master advanced programming concepts through hands-on coding.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion
2

Introduction to Game Design

Design and develop more complex games with advanced mechanics, scoring systems, and multiple levels. Learn game design principles and user experience concepts.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion
3

AI Literacy

Explore artificial intelligence concepts, machine learning basics, and AI tools. Learn how to effectively use AI in creative projects and understand its impact on society.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion
4

Web Development

Build your first websites using HTML, CSS, and modern web development tools. Create personal portfolios and interactive web applications to showcase your skills.

  • Hands-on Project
  • Mentorship Support
  • Certificate of Completion
